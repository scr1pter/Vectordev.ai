# Optional documentation social-card server notices

These packages support the optional hosted `/api/og` image renderer. They are not part of the Vector desktop or standalone CLI bundle. The renderer uses unmodified `@vercel/og@1.0.1`, Satori and resvg under MPL-2.0; full license terms are reproduced below. Exact npm source archives and integrity hashes are recorded for each package. The published renderer source maps include their TypeScript source content. The renderer publisher's declared repository commit was not independently available, so these notices identify the verified published archive instead.

Installed package archives were verified against the lockfile SHA-512 integrity before reading notice files. Embedded-only components were identified from the renderer source map and checked against their exact registry archive SHA-512 integrity. Missing package notices are explicitly supplemented or identified. License wording is reproduced in full; display-only line endings and trailing whitespace are normalized. Notice hashes refer to the original source text. Optional native entries cover the reviewed local macOS arm64 and production Linux x64/arm64 server closures. The libvips publisher's component license table is retained; LGPLv3/GPLv3 terms follow. These binaries and server libraries are not downloaded by the generated PNG recipient.

The bundled Geist font identifies version 1.800 and Copyright 2024 The Geist Project Authors (https://github.com/vercel/geist-font.git); the full SIL Open Font License 1.1 follows. The route accepts only bounded plain ASCII titles and no external assets, fonts, archives or images.
