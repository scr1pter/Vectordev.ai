## What it measures

The fixture is a small invented repository of 25 source files and 5 short specs for it (`packages/core/test/fixtures/knowledge`): 1,792 characters, about 423 tokens, read into 34 records. Recall runs the way a Light request does: the request's words, the files it touches, and at most the Light budget of cards. No language model is called. Search by meaning used the local search model, Snowflake/snowflake-arctic-embed-xs@d8c86521100d int8, on this computer: it embedded 49 records and passages in 0.9 s, running on the main thread as the test fixture runs it.

- **40 tasks** name the files they touch, mostly in words the governing requirement never uses ("change how long people stay signed in" while editing `src/auth/session.ts`).
- **8 tasks** edit a file that only imports the governed one, so no spec is linked to the edited file itself.
- **10 requests** ask about nothing the specs say, such as "hi" or "how do I center a div?".

A task counts as found when the governing requirement's sentence is in what the request carries.

## Limits

- The fixture is small and was written alongside the feature it measures. It shows that code links reach requirements keywords miss; it is not an independent benchmark, and it does not measure the quality of a model's answers.
- Times are from one run on the machine named above and change with the machine and its load.
- Search by meaning ran the pinned int8 model on this computer's CPU through ONNX Runtime's WebAssembly build; another machine embeds at another speed. Its floor (0.2, as a cosine less the mean every text shares) was set on this same fixture, where unrelated requests carried no cards from 0.18 up, and at 0.17 one of them carried 122 tokens, so the shipped floor sits 0.02 above the least that kept them out; the meaning columns are not an out-of-sample result.
- The 300-page PDF measures the keyword stage only; how long the model takes to embed it is not timed here.
- Token counts are Vector's estimate of what the recalled text costs, not a provider's count.
