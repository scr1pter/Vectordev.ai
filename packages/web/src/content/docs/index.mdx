[**Vector**](/) is a free BYOK AI coding workspace for developers who want a powerful coding agent without giving up control of their files, model choice, or API spend.

Vector is being shaped around three ideas:

1. Bring your own model key.
2. Keep your code as normal project files.
3. Use AI as a serious coding partner, not a locked black box.

## Install

Download the latest desktop build from the [Vector releases page](https://github.com/scr1pter/Vectordev.ai/releases/latest).

For command-line installs, Vector will use the same release flow once public binaries are published under the Vector repository.

## Model Keys

Vector is BYOK. Connect a provider key from the model company you want to use, then choose the model that fits your task. Stronger coding models will produce better plans, safer edits, and better multi-file work.

## Ownership

Vector is designed so projects stay as real files on your machine. You can inspect, edit, commit, export, and move your code without being trapped inside a hosted builder.
